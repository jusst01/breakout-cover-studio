BREAKOUT is an offline web-based cover art studio that allows you to create GTA-style covers with a unique pop-out hero effect.

## How to run
1. Install dependencies if necessary (none required for the app itself).
2. Run `node serve.ts` to start the development server.
3. Open `http://localhost:8080` in your browser.
